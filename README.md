Maak zelf in de repository hoofdmap een map "data" aan waarin de door jezelf gedownloade data staat. Hierin wordt ook de aangepaste data uit de medallion lagen opgeslagen.
Deze wordt bij het pushen naar github niet meegestuurd (zie de .gitignore file). Pas op dat je niet per ongeluk ook data naar github stuurt.

Bij direct laden van de G: schijf moeten handmatig de paths in db_file2parquet worden aangepast.
